# AutoPicker Pro v2.0.0 — 소비자용 내 차 찾기

국내외 자동차를 잘 모르는 사용자도 단계별로 조건을 고른 다음 **추천 → 차량 상세 → 구매 옵션 예산 → 관심 목록 저장 → 최종 비교**를 진행할 수 있는 정적 웹 앱입니다. 회원가입, 서버, API 키, 프레임워크 설치 없이 브라우저에서 실행합니다.

## 바로 실행

- **바로 열기:** `AutoPicker_Pro_Standalone.html` 파일을 더블클릭합니다. HTML/CSS/JS/차량 데이터가 포함된 단일 파일입니다.
- **GitHub Pages:** 저장소 최상위 폴더에 `index.html`, `styles.css`, `core.js`, `data.js`, `app.js`를 올립니다. GitHub **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** 설정 후 생성되는 URL로 접속합니다. GitHub Actions 워크플로우는 필요하지 않습니다.
- **로컬 개발:** 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`으로 접속합니다.

## 주요 기능

1. **초보자 안내형 9단계 설문:** 예산, 최대 탑승 인원, 차체 형태, 연료 방식, 충전환경, 연간 주행거리, 주차환경, 사용 목적, 국산/수입 선호.
2. **차량 검색/탐색:** 14개 브랜드, 77개 국내외 모델/동력 구성을 검색·정렬·필터링. 정적 기준 데이터(자동 실시간 업데이트는 아님).
3. **상대적 조건 충족 점수:** 최소 65% 보정 제거. 필수 좌석 수 미달 모델 배제, 충전 여건·예산 초과 등 조건 경고. 점수는 품질/신뢰성/안전 평가가 아닙니다.
4. **차량 상세:** 실제 모델 참고 사진과 출처 링크, 제조사 공식 사이트 연결. 이미지가 불러와지지 않으면 **다른 차 사진으로 바꾸지 않고** 안내 UI 표시.
5. **트림/옵션 예산:** 제조사 공개 가격표로 확인한 **일부 모델의 일부 선택품목**만 실제 품목/가격으로 표시(셀토스 1.6T 기본형, 쏘렌토 2.5T 기본형, 카니발 3.5 기본형, 레이 EV 4인승 기본형). 간단한 필수 옵션 의존성/배타 규칙 적용. 다른 모델은 자유 옵션 예산을 입력할 수 있습니다.
6. **구매 희망 기능 체크리스트:** HUD, 360도 카메라, 통풍 시트, 주행보조 등 관심 기능 저장. **해당 차량 장착 여부·선택 가능 여부를 보증하지 않으며, 체크리스트는 가격에 합산하지 않습니다.**
7. **계산기:** 차량 기본가, 선택품목, 추가 예산, 취득세율과 감면, 부대비용, 사용자가 확인한 EV 보조금, 선수금/할부 기간/연이율, 월 납입액 및 초기 필요 현금.
8. **최종 후보:** 브라우저 로컬 저장소에 관심 차량과 견적 저장, 최대 4대 비교, txt 견적 내보내기 및 복사.
9. **모바일 대응:** 390px 모바일·1440px 데스크톱 테스트.

## 가격 데이터 표시 원칙 — 중요

- `공식 시작가`: 2026년 10월 초 제조사 한국 공식 사이트에서 확인한 **대표 시작가격**입니다. 트림, 구동계, 세제 정책, 프로모션에 따라 변경됩니다.
- `참고 추정`: 최신 공식 국내 트림별 기본가를 확인하지 못한 차종에 대해 **비교용으로 임시 입력한 가격**입니다. 구매 판단 전에 공식 링크에서 반드시 확인해야 합니다. 실시간 시세가 아닙니다.
- EV 차종 중 일부 공식 시작가는 **개별소비세 혜택 후, 전기차 구매 보조금 전** 가격입니다. 국고/지자체 보조금은 자동 적용하지 않습니다.
- 세액은 `차량 총액 / 1.1 × 선택 취득세율`을 단순 추정하며, 지방채·공채·세금 관련 예외·면제 제도를 완전 반영하지 않습니다. **공식 등록 비용과 다를 수 있습니다.** 경차와 9인승 등은 계약 사양에 따라 직접 세율을 선택해야 합니다.
- 할부는 원리금 균등 추정이며, 등록비·보험료·금융 수수료·실제 채권 금액은 금융 상품과 지역마다 다릅니다.
- **이 서비스는 최종 계약 견적서가 아니며 판매자/금융기관을 대신하지 않습니다.**

## 이미지 출처와 사용

- 차량 사진은 **Wikimedia Commons의 실차 사진**을 우선 사용합니다. 17개 모델 구성에 직접 지정된 사진 URL이 있고, 나머지는 웹에서 Commons API로 **모델명과 라이선스가 부합하는 사진**을 조회합니다.
- Commons API에서 라이선스가 자유 이용(CC/PD)으로 확인되지 않으면 노출하지 않습니다. 업로더/라이선스는 각 사진의 `사진 출처 ↗`에서 확인하세요.
- 연식/외장/휠/트림/지역은 사용자가 구매할 모델과 다를 수 있으므로 사진을 정확한 실제 계약 옵션의 증거로 사용하지 마세요.
- 사진 이미지 바이너리는 이 패키지 안에 포함되어 있지 않습니다. **실제 사진 로딩에 네트워크가 필요**합니다. Wikimedia가 차단되거나 API 제한이 걸리면 안내용 플레이스홀더가 나옵니다.
- 코드와 UI 저작권과 사진 저작권은 별개입니다. 각 Wikimedia 저작자의 라이선스/저작자표시 조건을 따르세요.

## 유지보수와 테스트

- `vehicles.json`가 편집 가능한 데이터 원본입니다. `build_catalog.py`는 이번 버전의 일괄 생성용 소스이고, `data.js`를 재생성합니다. 데이터를 직접 수정한 경우 두 파일의 내용이 어긋나지 않게 관리하세요.
- `core.js`는 점수·견적·옵션 의존성 처리 로직, `app.js`는 화면과 로컬 상태 처리, `styles.css`는 스타일입니다.
- `node test_core.js` : 결정적 유닛 테스트 14개.
- `python test_smoke.py` : Playwright + Chromium 브라우저에서 주요 사용자 흐름과 모바일 레이아웃 확인.
- `python test_persistence.py` : 사용자가 저장한 목록의 직렬화 및 새 페이지 복원 확인(모의 저장소 환경).
- 수정 후 `python bundle.py` 실행 시 최신 단일 HTML을 다시 생성합니다.

## 품질·잔여 제약

현 버전에서 확인된 것은 **브라우저 작동 흐름과 계산 로직**입니다. 제조사 전 차종의 모든 트림·패키지 조합, 보험료, 지자체 보조금, 실시간 가격, 차대번호별 옵션 등은 데이터 계약/정기 검수 없이 정확하게 구현할 수 없으므로 이 버전에는 포함하지 않았습니다. 시승예약/구매 계약은 제공하지 않습니다.
