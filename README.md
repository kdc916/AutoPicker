## 주요 기능

1. **기본정보 선입력 + 5단계 적응형 질문:** 탑승 인원·총예산·연간 주행거리·충전 여건·10가지 필수 옵션을 먼저 입력하고, 나머지 취향만 질문. 다인승·충전·어라운드뷰 선택 시 질문 문구와 차체 후보가 달라집니다.
2. **차량 검색/탐색:** 14개 브랜드, 77개 국내외 모델/동력 구성을 검색·정렬·필터링. 정적 기준 데이터(자동 실시간 업데이트는 아님).
3. **상대적 조건 충족 점수:** 최소 65% 보정 제거. 필수 좌석 수 미달 모델 배제, 충전 여건·예산 초과 등 조건 경고. 점수는 품질/신뢰성/안전 평가가 아닙니다.
4. **차량 상세:** 실제 모델 참고 사진과 출처 링크, 제조사 공식 사이트 연결. 이미지가 불러와지지 않으면 **다른 차 사진으로 바꾸지 않고** 안내 UI 표시.
5. **트림/옵션 예산:** 8개 모델의 20개 제한된 트림을 공식 공개가/선택품목으로 매핑. 체크된 필수 기능을 만족하는 최저 가격 트림·패키지를 찾아 총액에 반영. 사양 미검증 모델은 '확인 필요'로 명시.
6. **옵션 체크리스트 및 자동 재추천:** 어라운드뷰, HUD, 통풍, 주행보조, 전동 트렁크 등의 검증된 기본 포함/유료 패키지 매핑. 상세에서 기능을 바꾸면 자동 재추천 버튼으로 적정 트림 선택. 주행보조는 완전 자율주행 아님.
7. **계산기:** 차량 기본가, 선택품목, 추가 예산, 취득세율과 감면, 부대비용, 사용자가 확인한 EV 보조금, 선수금/할부 기간/연이율, 월 납입액 및 초기 필요 현금.
8. **최종 후보:** 브라우저 로컬 저장소에 관심 차량과 견적 저장, 최대 4대 비교, txt 견적 내보내기 및 복사.
9. **모바일 대응:** 390px 모바일·1440px 데스크톱 테스트.
